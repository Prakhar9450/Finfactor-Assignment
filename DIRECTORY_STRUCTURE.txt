CACHE ARCHITECTURE
==================

Cache Type: LRU (Least Recently Used)
Max Size: 50 entries
Expiry: 6 hours
Location: In-memory (server-side)

Cache Keys:
  apod_YYYY-MM-DD ──────────────────► Single APOD
  apod_range_YYYY-MM-DD_YYYY-MM-DD ─► Date range

Eviction Strategy:
  1. Check if key exists
  2. Check if expired (timestamp > 6h)
  3. If cache full, remove oldest entry
  4. Add new entry at end (most recent)


API SPECIFICATIONS
==================

Endpoint: GET /api/apod/today
Response: { success: true, data: ApodResponse, cached: boolean }
Cache: Yes (6 hours)

Endpoint: GET /api/apod/date?date=YYYY-MM-DD
Params: date (required, format: YYYY-MM-DD)
Validation: Must be between 1995-06-16 and today
Response: { success: true, data: ApodResponse, cached: boolean }
Cache: Yes (6 hours)

Endpoint: GET /api/apod/range?start=YYYY-MM-DD&end=YYYY-MM-DD
Params: start (required), end (required)
Validation: Max range of 100 days
Response: { success: true, data: ApodResponse[], cached: boolean }
Cache: Yes (6 hours)
